## What would fix it

**Minimum**

- x86-64, 4 cores or better
- 16 GB RAM (8 GB is workable, 16 GB removes the ceiling)
- NVMe SSD, 256 GB or larger
- Runs Linux with no out-of-tree driver fights

**Helpful**

- 32 GB RAM (local Android emulator + Rust release builds at the same time)
- USB-C with DisplayPort alt mode
- User-replaceable battery and SSD

_Not asking for the newest or the fastest. Refurbished, previous-generation, or review-unit hardware all do the job._

## What I give back

1. **A public build log** — what shipped each week and what broke, on the actual hardware.
2. **A written Linux compatibility report** — what worked, what needed a quirk, what I would tell the next buyer. Published with attribution, unedited.
3. **Upstream fixes** — driver quirks, packaging bugs and kernel problems become patches and bug reports.
4. **It stays in circulation** — if it is replaced later, it goes to another maintainer, not a drawer.

## Scope

This is not a mailing list and there is no form. One message per organisation, sent once, to the address that organisation publishes for this kind of enquiry. No follow-ups unless someone replies.
